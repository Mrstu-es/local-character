# Estado verificable — 17 de agosto de 2026

## Verificado en Windows x64

- `cargo check` y `npm.cmd run build` pasan.
- `npm.cmd run tauri build` genera NSIS y MSI.
- El EXE se inicia y permanece activo; los procesos de `llama-cli`, `nvidia-smi` y `vulkaninfo` se crean con `CREATE_NO_WINDOW`.
- El instalador incluye los DLL de llama.cpp CPU y el icono derivado de `app/src/main/res/drawable/ic_launcher_foreground.xml`.
- SQLite aplica migraciones versionadas hasta la versión 2 sin borrar datos existentes.

## Funcionalidad implementada

- Registro de modelos GGUF y carga/descarga mediante llama.cpp real.
- Streaming, cancelación y captura de stderr/exit code en el panel de diagnóstico.
- Chats y mensajes persistidos en SQLite, con conversaciones separadas.
- Benchmark real contra llama.cpp con TTFT, tokens generados y tokens/segundo guardados en SQLite.
- Biblioteca de personajes con avatar local y Character Card v2 JSON/PNG (incluye alternate greetings, tags y lorebook).
- Ajustes locales de idioma, tema, contexto y capas GPU.
- Esquema preparado para memoria, relaciones, grupos, proveedores, voces, feedback, ramas y uso.
