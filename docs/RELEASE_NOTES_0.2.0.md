# Local Character 0.2.0 — Desktop + Android

Esta entrega reúne la aplicación Android y la primera versión distribuible de Local Character Desktop para Windows.

## Novedades de Desktop

- Nueva interfaz responsive de roleplay para Windows.
- Personajes, chats, grupos y memoria en una pantalla de conversación dedicada.
- Importación de avatares y Character Cards.
- Registro y carga de modelos GGUF locales.
- Integración real con llama.cpp y streaming cancelable.
- Detección de CPU, RAM, GPU NVIDIA/Intel y dispositivos Vulkan.
- Selección de backend GPU, CPU o híbrido, con prioridad automática a la GPU discreta.
- Repositorios de personajes y voces TTS administrables desde Ajustes.
- Proveedores de APIs externas con selección de modelos.
- Capturas y documentación organizadas por plataforma.

## Android

La aplicación Android mantiene el flujo local-first: personajes y conversaciones permanecen en el dispositivo, con Character Cards, chats grupales, memoria, repositorios, voces TTS, modelos GGUF y APIs BYOK.

## Descargas

Los instaladores de Windows y el APK de Android están publicados como assets de esta release. Los modelos GGUF se descargan por separado y no se incluyen en GitHub.
